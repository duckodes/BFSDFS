# BFS／DFS 迷宮練習

這個小工具可以看 BFS 和 DFS 怎麼探索迷宮，也可以自己改 JavaScript、跑完看看結果並註冊用戶上傳排行。

## 開啟方式

點選 [開啟 BFS／DFS 迷宮練習](https://duckodes.github.io/BFSDFS) 即可開始使用。

## 挑戰迷宮

1. 按「挑戰模式：自己寫算法」。
2. 在編輯器裡修改 `solve` 函式。編輯器預設放了一份 BFS，可以直接試跑，再慢慢修改。
3. 函式要回傳 `{ path, explored }`：
   - `path` 是從起點走到終點的格子 ID。
   - `explored` 是算法實際探索過的格子。
   - 格子 ID 的格式是 `"列,欄"`，例如 `"2,5"`。
4. 按「完成並評分」看路徑、探索格數、等待時間和分數。

也可以輸入迷宮碼重玩同一張地圖。迷宮碼相同，地圖、起點、終點就相同。

## 排行榜

上傳成績需要登入。玩家姓名會存到帳號資料中，不能和其他玩家重複；登入後可用「更改玩家姓名」修改排行榜上的顯示名稱。每個帳號在每張迷宮只保留個人最佳成績；分數沒有高於原紀錄時，不會顯示上傳按鈕。
