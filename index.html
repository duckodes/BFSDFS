每次會隨機生成迷宮，也可以輸入排行榜上的迷宮碼重現同一張地圖。完成評分後會依該迷宮的最短路徑長度與 BFS 必須探索的格數，顯示 1–10 難度級別。

請自行完成 JavaScript 的搜尋算法，再按「完成並評分」。系統會在隔離的執行環境中執行你的程式、驗證路徑，並依路徑長度與探索格數評分。提示：BFS 使用先進先出的佇列；DFS 使用後進先出的堆疊或遞迴。

評分方式：路徑品質最高 40 分、探索格數最高 40 分、實際等待時間最高 20 分。探索格數越少，探索分越高；從按下「完成並評分」到迷宮動畫結束的總等待時間越短，時間分越高（以 5 秒為 0 分基準線性遞減）。迷宮難度 1–10 依參考 BFS 的最短路徑長度與探索格數計算；同難度可作大致比較，迷宮碼相同才代表完全相同的地圖。未抵達得 1 分；算法執行超過 5 秒會停止。結果會分別顯示實際等待時間與算法本身的執行時間；時間複雜度參考：理想 BFS／DFS 為 O(V + E)，V 是可走格數、E 是相鄰連線數。

提供給算法的資料與 API 

      
函式必須命名為 solve，並回傳 { path, explored }。兩者都是格子 ID 字串陣列；explored 要記錄呼叫 getNeighbors 擴展過的格子，找到終點後也要把終點列入。計分等待時間包含算法執行、結果處理及迷宮動畫。

一層一層往外找；在這個每一步代價相同的迷宮中，找到的路徑步數最少。

      

        
      

      
    

    

      
DFS：深度優先搜尋

      
先沿著岔路往前走，走不通再回頭；找到終點就停止，不保證路徑最短。
